**Вход:** в панели укажите почту владельца организации Supabase и нажмите «Войти по ссылке из письма». Пароль из переписки не требуется. После входа откройте нужный вопрос кнопкой «Открыть»; до этого участник видит экран ожидания. Для репетиций создайте отдельное тестовое событие, чтобы не смешивать тестовые фразы с ответами форума.

После успешной автоматической публикации откройте последний зелёный запуск [Publish forum](https://github.com/iriniLou/forumdialog/actions/workflows/publish.yml). Внизу страницы находится архив **forum-links-and-qr**: внутри три проверенные ссылки, QR в SVG и результаты проверки. До успешной проверки архив с QR не создаётся. Не используйте предполагаемый адрес вместо проверенного.

Владельцу организации Supabase отправляется письмо-приглашение. Откройте ссылку из письма; пароль в переписке не нужен. Для повторного входа укажите эту же почту в панели и нажмите «Войти по ссылке из письма». Ссылка одноразовая. Если нужна отдельная команда модераторов, администратор проекта добавляет их учётные записи и роли; приглашение владельца не даёт доступ всем участникам.

Перед началом:

1. Откройте панель организатора и загрузите событие (код заполнится автоматически).
2. Откройте «Так что же для вас „Разговоры о важном“?».
3. На двух телефонах откройте QR, отправьте по вымышленной тестовой фразе в отдельном тестовом событии.
4. Убедитесь, что без одобрения фраз нет на проекторе. Одобрите одну, затем скройте её.
5. Переключитесь обратно на настоящее пустое событие, откройте вопрос и полноэкранный проектор.

Дополнительный цифровой вопрос позволяет анонимно прислать вопрос или проблему из практики: оператор открывает его в нужный момент. Это отдельный интерактив; устные блоки не требуют телефонов.

Реплики из зала записывайте дословно по смыслу, без личных данных, через «Фиксацию ответов из зала». Выберите «Сработало», «Было трудно», «Решения» или «Вопросы». До одобрения они не публикуются. Ошибку набора можно исправить; оригинал останется в закрытой истории.

В конце скачайте CSV, XLSX и Markdown. Это основа памятки для редактора, а не автоматически утверждённые рекомендации. Для резервной презентации заранее скачайте PNG нужных вопросов и вставьте их в свои слайды. При сбое сети — голосовые ответы, жестовое голосование и бумага. «Аварийно закрыть всё» прекращает приём и скрывает экран при следующем успешном обновлении.

Действующая дофоромная анкета и исходная Google-таблица не изменяются. Для статистики импортируется только вручную проверенный обезличенный агрегат без жёлтых пробных строк.

Перед выступлением откройте нужный блок и нажмите **Обновить срез**. Исправьте счётчики, N, дату/время и описание выборки. Сумма категорий должна совпасть с N. Нажмите **Сохранить срез** — проектор обновится при следующем запросе, без переустановки и повторной публикации. Старые значения сохраняются в закрытой истории, доступной администратору в JSON-экспорте. Если другой администратор успел изменить данные, откройте форму заново с новым срезом.
