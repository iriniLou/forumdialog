# Сценарий 13 ноября 2026 · 10:00–11:30 МСК

1. В начале цифровой вопрос: «Что для вас „Разговоры о важном“?» (80 символов). Модератор выбирает 6–10 реплик. Оператор закрывает приём.
2. Шесть устных блоков: изменения 2026/2027; проведённые темы, успехи и трудности; подготовка и время; видео без обсуждения; ответ критически настроенному подростку; продолжение после звонка. Секретарь вводит реальные слова, модератор подтверждает. Это качественный материал, без N и процентов.
3. Три самостоятельных источника: материалы мониторинга Института (только после подтверждения), агрегаты анкеты до форума (без тестов), слова зала. Не смешивать выборки.
4. Сравнение тем разных возрастов, затем загруженный реальный фрагмент сценария. До загрузки — честная заглушка.
5. Итоговая доска: трудности / работающие практики / решения / вопросы без ответа. Экспертный ответ отмечается отдельно. Редактор выгружает Markdown/CSV/JSON для рабочей памятки.

Если нет интернета: короткие голосовые ответы и бумага; заранее подготовленные PNG вставлены в резервный PPTX. Автоматическое согласие на будущую фокус-группу из анонимных ответов не выводится.

По уточнению организатора предусмотрен второй цифровой интерактив: анонимный вопрос или проблема из практики. Оператор открывает его в нужный момент; остальные вопросы остаются устными.
